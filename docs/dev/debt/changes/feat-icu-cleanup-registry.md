# libSceIcu

## change [Cleanup]

- [Cleanup](../../../core/libs/prx/libSceIcu/Configuration.cpp) is unverified on a console. `u_cleanup` follows ICU 78.1 [ucln_cmn.cpp](https://github.com/unicode-org/icu/blob/049e0d6a420629ac7db77256987d083a563287b5/icu4c/source/common/ucln_cmn.cpp) for the state this module keeps: it first calls, once each and in library order, the cleanup functions registered with [ucln_registerCleanup](../../../core/libs/prx/libSceIcu/Cleanup.cpp), then clears the functions stored by `u_setMemoryFunctions` and resets the data and time zone files directories. `ucln_registerCleanup` ignores a library type outside `UCLN_UPLUG` to `UCLN_I18N` and `ucln_cleanupOne` throws for one, where ICU indexes past its table. Pointers returned earlier by the directory getters are invalidated, as in ICU. ICU's tracing and common-library cleanup chains have no counterpart here. The NIDs come from the 3.20 inventory and their presence on current firmware is unproven (see ICU export availability). Closes when: compared with the console.
