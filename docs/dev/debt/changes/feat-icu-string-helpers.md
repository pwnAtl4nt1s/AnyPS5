# libSceIcu

## add Functional

- [String hashes](../../../core/libs/prx/libSceIcu/Hash.cpp) are unverified on a console. `ustr_hashUCharsN`, `ustr_hashCharsN` and `ustr_hashICharsN` follow `STRING_HASH` in ICU 68.2 [ustring.cpp](https://github.com/unicode-org/icu/blob/release-68-2/icu4c/source/common/ustring.cpp), unchanged in ICU 78.1: from the first unit, every `((length - 32) / 32) + 1`th unit is folded in as `hash * 37 + unit`, with bytes read unsigned and `ustr_hashICharsN` lowering ASCII `A`-`Z` only; a null string or a length of zero or less hashes to 0. The signatures are ICU's internal `ustr_imp.h` ones; no title call site was read.
- [Hash keys](../../../core/libs/prx/libSceIcu/Hash.cpp) are unverified on a console. `uhash_hashUChars`, `uhash_hashChars`, `uhash_hashIChars`, `uhash_hashLong`, `uhash_compareUChars`, `uhash_compareChars`, `uhash_compareIChars` and `uhash_compareLong` follow ICU 68.2 [uhash.cpp](https://github.com/unicode-org/icu/blob/release-68-2/icu4c/source/common/uhash.cpp): the 8-byte `UElement` key is passed by value, string keys hash their whole NUL-terminated string through the `ustr_hash` functions, a null key hashes to 0 and equals only another null key, `uhash_compareIChars` folds ASCII only, and the integer forms read the low 32 bits. `UBool` is returned as an 8-bit integer, as in ICU 68.
- [String enumerations](../../../core/libs/prx/libSceIcu/Enumeration.cpp) are unverified on a console. `uenum_openCharStringsEnumeration`, `uenum_openUCharStringsEnumeration`, `uenum_reset`, `uenum_unextDefault` and `uenum_nextDefault` follow ICU 68.2 [ustrenum.cpp](https://github.com/unicode-org/icu/blob/release-68-2/icu4c/source/common/ustrenum.cpp) and [uenum.cpp](https://github.com/unicode-org/icu/blob/release-68-2/icu4c/source/common/uenum.cpp): the enumeration keeps the caller's array, invalid arguments return null without setting an error, and converted strings live in the `baseContext` buffer, grown by 8 extra bytes, that `uenum_close` frees. That buffer and the enumerations are now allocated and freed through the ICU allocator (`u_setMemoryFunctions`), as ICU does, where `uenum_close` used the guest `free` before. `uenum_nextDefault` throws for a null result length, which ICU dereferences; `uenum_openFromStringEnumeration`, which wraps a guest C++ object, still throws.
- [ASCII character helpers](../../../core/libs/prx/libSceIcu/CString.cpp) are unverified on a console. `uprv_isASCIILetter`, `uprv_toupper`, `uprv_asciitolower`, `uprv_ebcdictolower`, `uprv_stricmp` and `uprv_strnicmp` follow the ASCII-family build of ICU 68.2 [cstring.cpp](https://github.com/unicode-org/icu/blob/release-68-2/icu4c/source/common/cstring.cpp): only ASCII letters change case, `uprv_ebcdictolower` maps the EBCDIC capitals 0xC1-0xC9, 0xD1-0xD9 and 0xE2-0xE9 down by 0x40, and the comparisons order a null string first, a prefix before a longer string, and otherwise return the difference of the lowered unsigned bytes, `uprv_strnicmp` comparing at most its count. `UBool` is returned as an 8-bit integer, as in ICU 68.
