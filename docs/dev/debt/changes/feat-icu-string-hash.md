# libSceIcu

## add Functional

- [String hashes](../../../core/libs/prx/libSceIcu/Hash.cpp) are unverified on a console. `ustr_hashUCharsN`, `ustr_hashCharsN` and `ustr_hashICharsN` follow `STRING_HASH` in ICU 68.2 [ustring.cpp](https://github.com/unicode-org/icu/blob/release-68-2/icu4c/source/common/ustring.cpp), unchanged in ICU 78.1: from the first unit, every `((length - 32) / 32) + 1`th unit is folded in as `hash * 37 + unit`, with bytes read unsigned and `ustr_hashICharsN` lowering ASCII `A`-`Z` only; a null string or a length of zero or less hashes to 0. The signatures are ICU's internal `ustr_imp.h` ones; no title call site was read.
- [Hash keys](../../../core/libs/prx/libSceIcu/Hash.cpp) are unverified on a console. `uhash_hashUChars`, `uhash_hashChars`, `uhash_hashIChars`, `uhash_hashLong`, `uhash_compareUChars`, `uhash_compareChars`, `uhash_compareIChars` and `uhash_compareLong` follow ICU 68.2 [uhash.cpp](https://github.com/unicode-org/icu/blob/release-68-2/icu4c/source/common/uhash.cpp): the 8-byte `UElement` key is passed by value, string keys hash their whole NUL-terminated string through the `ustr_hash` functions, a null key hashes to 0 and equals only another null key, `uhash_compareIChars` folds ASCII only, and the integer forms read the low 32 bits. `UBool` is returned as an 8-bit integer, as in ICU 68.
