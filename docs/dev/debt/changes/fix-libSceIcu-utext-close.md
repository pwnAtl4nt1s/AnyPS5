# libSceIcu

## change [ICU UText exports]

- [ICU UText exports](../../../core/libs/prx/libSceIcu/UText.cpp) are unverified on a console; `utext_openUnicodeString`, `utext_openConstUnicodeString`, `utext_openReplaceable` and `utext_openCharacterIterator`, which wrap guest C++ objects, still throw, and a null `UText` or status throws where ICU dereferences it. The rest of ICU 68.2 [utext.cpp](https://github.com/unicode-org/icu/blob/84e1f26ea77152936e70d53178a816dbfbf69989/icu4c/source/common/utext.cpp) is ported onto ICU's 64-bit `UText` and `UTextFuncs` layouts: setup, close, iteration, indexing, extract, clone and the UTF-8 and `UChar` providers, whose guest-ABI callbacks sit in `pFuncs`; memory comes from the ICU allocator. `utext_current32` keeps ICU 68's offset restore after a cross-chunk trail lookup, which ICU 78 changed. The test runs random sequences on well- and ill-formed UTF-8 and UTF-16 and compares every result and chunk field with ICU 78's `utext.cpp`. Closes when: compared with the console.
